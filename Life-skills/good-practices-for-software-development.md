# Good Practices for Software Development

## Question 1: Which points were new to you?
- Over-communicating about delays and issues
- Receiving calls and calling back instead of ignoring them
- Using screenshots, Loom, and GitHub gists while asking questions
- Joining meetings early to build rapport
- Sending consolidated questions instead of multiple small messages
- Managing food, exercise, and attention for better productivity

## Question 2: Which area do you need to improve? How will you improve?
- I need to improve on over-communication.
- I sometimes try to solve issues silently instead of informing early.
- I will update the team immediately if there is a delay.
- I will ask clearer questions with context and attempted solutions.
- I will track my focused work time daily.
- I will reduce distractions during work hours.
